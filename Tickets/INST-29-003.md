# INST-29-003 — Fix: SERVER_IP unbound variable en print_success()

**Épica:** 29 — Zero-Friction First Access
**Repo:** Aegis-Installer
**Asignado a:** DevOps Engineer
**Prioridad:** 🔴 Crítica — crashea el installer al final, después de que todo funcionó
**Estado:** DONE
**Depende de:** ninguno — fix independiente

---

## Contexto

El installer termina con error aunque los contenedores quedaron corriendo correctamente:

```
/dev/fd/63: línea 469: SERVER_IP: variable sin asignar
```

Con `set -euo pipefail` activo, la referencia a `$SERVER_IP` dentro de `print_success()` falla porque `SERVER_IP` no está declarada como variable global al inicio del script. La opción `-u` de bash trata las variables no declaradas como error.

---

## Trabajo requerido

### Archivo: `install_aegis.sh` — sección `--- Configuration ---`

Leer antes de modificar:
```javascript
read_file(repo: "Aegis-Installer", file_path: "install_aegis.sh")
```

En la sección de variables globales (donde están `INSTALL_ROOT`, `NEW_INSTALLATION`, etc.), agregar:

```bash
SERVER_IP=""
```

Esto declara la variable vacía antes de que `set -euo pipefail` entre en efecto, eliminando el error de variable sin asignar.
