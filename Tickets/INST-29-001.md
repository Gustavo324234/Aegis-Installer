# INST-29-001 — Setup Token: imprimir URL+token al final del installer

**Épica:** 29 — Zero-Friction First Access
**Repo:** Aegis-Installer
**Asignado a:** DevOps Engineer
**Prioridad:** 🔴 Alta
**Estado:** TODO
**Depende de:** ANK-29-001 (el Kernel debe generar el token)

---

## Contexto

El installer actualmente termina mostrando la IP del servidor pero no indica cómo hacer el primer acceso. El usuario necesita saber que debe usar un token para el setup inicial. El token lo genera el Kernel en sus logs al arrancar sin Master Admin.

---

## Trabajo requerido

### Archivo: `install_aegis.sh` — función `print_success()`

Leer antes de modificar:
```javascript
read_file(repo: "Aegis-Installer", file_path: "install_aegis.sh")
```

En `print_success()`, después de levantar los contenedores, esperar que el ANK esté listo y extraer el token de sus logs:

```bash
print_success() {
    SERVER_IP=$(hostname -I 2>/dev/null | awk '{print $1}') || SERVER_IP="localhost"
    if [ -z "$SERVER_IP" ]; then
        SERVER_IP="localhost"
    fi

    # Wait for ANK to be ready (max 30 seconds)
    log "Waiting for Aegis Neural Kernel to initialize..."
    local attempts=0
    until docker logs aegis-ank 2>&1 | grep -q "KernelService.*levantado\|setup_token=\|already initialized"; do
        sleep 2
        attempts=$((attempts + 1))
        if [ "$attempts" -ge 15 ]; then
            warn "ANK initialization timeout — check logs with: docker logs aegis-ank"
            break
        fi
    done

    # Try to get setup token from logs
    local setup_token
    setup_token=$(docker logs aegis-ank 2>&1 | grep "setup_token=" | tail -1 | sed 's/.*setup_token=\([^ ]*\).*/\1/' 2>/dev/null || echo "")

    echo -e "${GREEN}################################################################${NC}"
    echo -e "${GREEN}#          AEGIS OS - DEPLOYMENT COMPLETED                      #${NC}"
    echo -e "${GREEN}################################################################${NC}"
    echo ""

    if [ -n "$setup_token" ]; then
        echo -e "${CYAN}  FIRST TIME SETUP:${NC}"
        echo -e "  Open this URL in your browser:"
        echo ""
        echo -e "  ${GREEN}http://$SERVER_IP:8000?setup_token=$setup_token${NC}"
        echo ""
        echo -e "  Token expires in 30 minutes."
        echo -e "  If it expires, run: ${CYAN}sudo aegis-token${NC}"
    else
        echo -e "  Aegis Shell: ${CYAN}http://$SERVER_IP:8000${NC}"
    fi

    echo ""
    echo -e "  To uninstall: ${YELLOW}sudo bash /opt/aegis/Aegis-Installer/uninstall_aegis.sh${NC}"
    echo -e "${GREEN}################################################################${NC}"
}
```

## Criterios de aceptación

- [ ] El installer imprime la URL con el token al finalizar si es instalación nueva sin admin
- [ ] Si el admin ya existe (reinstalación), muestra la URL normal sin token
- [ ] Si el token no se puede extraer de los logs (timeout), muestra instrucción de `sudo aegis-token`
- [ ] `shellcheck install_aegis.sh` pasa sin warnings nuevos
- [ ] `bash -n install_aegis.sh` pasa
